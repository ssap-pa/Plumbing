# 비원스토리지 스타일 게시글 템플릿

근거: `post-structure-analysis.md` 2절(비원스토리지 블록 순서). 시공 글 6건 공통 구조를 옮긴 것이다.
`{ }` 안은 입력 양식 값으로 치환한다. `○○설비`, `시공대장`은 상호·닉네임 확정 후 고정한다.

## 수치 목표

| 항목 | 목표 | 벤치마크 |
|---|---|---|
| 본문 글자 수 | 1,200~2,600자 | 평균 1,660 |
| 글 블록 | 15~20개 | 20.1 |
| 사진 묶음 | 8~10개 | 10.2 |
| 사진 장수 | 15~30장 | 24.1 |
| 스티커 | 4~5개 | 4.6 |
| 구분선 | 4~6개 | 4.8 |
| 지도 | 1개, 3~5번째 블록 | 6/8건 |
| 인용구 | 0~1개 ("중요한 포인트") | 0.2 |
| 링크 | 0~2개 (이전 글, 자재 상품) | 0.8 |
| 첫 글 블록 | 20~60자 (인사말만) | 35 |
| 마지막 글 블록 | 80~250자 (마무리 + 해시태그) | 192 |
| 줄 길이 | 한 줄 10~15자, 문장 중간에서 줄바꿈 | 문단당 12자 |
| 캡션 | 사용 안 함 (사진 앞 글이 소제목) | 0.4 |
| 업체명 반복 | 3회 (인사, 마무리, 해시태그) | 3.2 |
| "시공" | 10회 이상 | 12.6 |
| 본문 해시태그 | 22~32개, 마지막에 몰아서 | 28.6 |
| 태그 | 30개 | 26.4 (중앙값 30) |

## 제목

```
{건물명 또는 지역} {건물 유형} {용도·평수} {제품 브랜드} l {작업1} & {작업2} {작업3} 시공 by ○○설비 안산 시공대장
```
- 50~60자
- 작업 나열 구분자: `l`, `ㅣ`, `&`, `N`, `/` 중 하나로 글마다 통일
- 접미어 `시공 by ○○설비 안산 시공대장` 고정
- 예: `안산 고잔동 ○○아파트 욕실 리모델링 라우체 l 매립세면수전 & 매립샤워수전 시공 by ○○설비 안산 시공대장`
- 예: `안산 중앙동 상가 2층 고기집 5평 습식주방 트랜치 설비 조적 방수 타일 공사 시공 by ○○설비 안산`

```
        "뭐 큰 문제는 없을 겁니다. 항상 잘해오던 방식대로 ~하면 되는 현장이니까요~" 식의 구어체 1줄}

[스티커]

[사진 1~6장]
[글] {설명 3~12줄, 줄당 10~15자}
     - 작업 내용 1~2줄
     - 이렇게 하는 이유 2~4줄 ("~인거 아시죠?", "~다들 알고 계시죠?" 구어체 질문 1개 이내)
     - 수치·자재 1줄 (50A PVC, 트랜치보다 20mm 높게, 양생 1일 등)
     - "물론~ 소비자분은 모르셔도 됩니다. 이런 건 ○○설비 시공대장이 알아서 척척해드리니 연락만 주시면 됩니다." 류 1줄 (글당 1~2회)
[스티커 / 구분선 / 인용구 / 링크]  ← 공정 2~3개마다 하나
──────────────────────────────

[인용구] 중요한 포인트 / {주의 사항 2~3줄}       ← 글당 0~1회

[링크] {이전 편 글} 또는 {사용 자재 상품}           ← 본문 중간

[글 ⑫] {완료 사진 뒤 마무리 5~8줄}
        {지역} {용도}
        누수 걱정 없는 완벽한 {작업}의 모든 것
        ○○설비 시공대장과
        함께 하면 쉽게 할 수 있습니다.

        연락주세요~

[글 ⑬] #{해시태그} × 22~32개  (줄바꿈으로 나열)
```

## 소제목 규칙

- 공정명을 해시태그로: `#트랜치설비`, `#탄성도막방수`, `#몰탈침투방수`, `#도막코팅방수`, `#타일`, `#줄눈시공`
- 차수 표기: `2차 #탄성도막방수`, `4차 #도막코팅방수`
- 복합 공정: `메인배수 이설 & 급수 설비`, `물턱 조적 및 1차 몰탈액체방수`, `급수설비 & 3차 물매침투방수`

## 해시태그·태그 (30개)

세 축을 조합해 30개를 채운다.
```
지역×작업:  안산{작업}, {동}{작업}, 시흥{작업}, 군포{작업}, 안양{작업}, 수원{작업}
            (예: 안산매립수전, 고잔동욕실리모델링, 시흥습식주방, 군포매립수전)
평수×작업:  3평주방설비, 4평주방설비, 5평주방설비, 3평습식주방, 4평습식주방
업종×작업:  고기집주방설비, 오마카세주방설비, 카페설비, 미용실설비, 피부샵설비
공정:       트랜치설비, 탄성도막방수, 몰탈침투방수, 타일마감선, 매립수전시공, 수도내림공사
제품:       라우체, 비반트, 폼세라믹, PB관시공, 에이콘부속
대상:       음식점주방, 2층습식주방, 하이엔드욕실, 호텔식욕실, 노후빌라수도공사
고정:       ○○설비, 시공대장, 안산시공대장, 설비전문업체
```
- 게시글 태그 1~2번째: `○○설비`, `시공대장`
- 본문 해시태그와 게시글 태그는 같은 목록 사용
