# 게시글 작성 입력 양식

공사 후 아래 항목을 채워서 사진과 함께 전달하면, 선택한 스타일 템플릿대로 글을 작성합니다.
빈칸은 비워 둬도 됩니다. 사진은 파일명 순서가 작업 순서가 되도록 정리합니다.

```
[스타일]  에프원 / 비원 / 혼합(안산 기본)   ← 하나 선택

[현장]
- 지역: 안산시 상록구 사동
- 건물명: ○○아파트 (지도 검색용 정식 명칭)
- 건물 유형: 아파트 / 빌라 / 오피스텔 / 단독주택 / 상가 / 공장
- 평수·칸수: 욕실 2칸 / 주방 5평 등
- 업종(상가일 때): 이자카야 / 미용실 / 카페 등

[의뢰]
- 증상: 싱크대 물이 안 내려감, 아랫집 천장 누수 등
- 고객이 말한 내용: 수도요금 2배 올랐다, 다른 업체 견적 700 나왔다 등
- 긴급 여부 / 영업 중 여부:

[진단]
- 확인 방법: 육안 / 내시경 / 청음 탐지 / 가스 탐지 / 수압 검사
- 원인: 기름 축적, 온수배관 핀홀, 부속 균열 등
- 예상과 달랐던 점:

[작업 순서]  ← 사진 묶음 하나가 한 줄
1. 공정명: 사진 번호 / 사용 장비·자재 / 설명 한두 줄
2. 공정명: ...
3. ...
마지막. 시공 완료: 사진 번호

[사용 자재·장비 브랜드]  (제목·태그에 씀)
- 예: 코텐 레이저 레벨기, 라우체 매립수전, PB 16mm, 50A PVC

[결과]
- 작업 후 확인한 것: 통수 영상, 수압 재검사 등
- 고객 반응:
- 소요 시간 / 방문 횟수:

[연재]
- 같은 현장 이전 글 링크:
- 다음 편 예정 공정:

[동영상]
- 파일명 / 내용 / 넣을 위치(공정 번호):

[제외 요청]
- 노출하면 안 되는 정보(동·호수, 상호, 고객 얼굴 등):
```

## 사진 전달 규칙

| 항목 | 기준 (벤치마크 수치) |
|---|---|
| 장수 | 에프원 스타일 12~20장, 비원 스타일 15~30장 |
| 순서 | 파일명 앞에 번호 (01_현장.jpg, 02_내시경.jpg …) |
| 묶음 | 공정 하나당 1~6장. 에프원은 묶음 4개 안팎, 비원은 묶음 8~10개 |
| 마지막 | "시공 완료" 사진 1~4장 (에프원 9건 모두 마지막 묶음이 시공 완료) |
| 제외 | 호수·문패·우편물·고객 얼굴이 찍힌 컷 |

## 출력물

작성 결과는 아래 형식으로 돌려드립니다. 스마트에디터에 순서대로 옮겨 붙이면 됩니다.

```
[제목] ...
[태그] 태그1, 태그2, ... (에프원 20개 / 비원 30개)

--- 본문 ---
[글] ...
[지도] 건물명 (검색어)
[구분선]
[사진 01~04] 캡션: ...
[글] ...
[스티커]        ← 비원 스타일만
[인용구] ...    ← 필요할 때
[링크] ...      ← 연재·상품
[동영상] 파일명
...
```
